# Social Media Engagement Data Analysis

Group Members: Sachi Verma, Joseph Acquah, Lakshmi Sangireddi, Mohit Batchu, Mahatab Hussain

Chosen data set: https://www.kaggle.com/datasets/subashmaster0411/social-media-engagement-dataset/data

Why we chose this dataset:
We chose this dataset because it includes a broad range of quantitative data and qualitative traits, such as sentiment_score, impressions, engagement_rate, and user_engagement_growth. We chose it because it relates to a topic many people our age are surrounded by: social media. Along with the quantitative features discussed above, it also includes more specific measures such as likes, shares, comments, impressions, sentiment, toxicity, and changes in attention over time, all variables can be useful in the marketing space for understanding audience behavior, how different people react to different sentiments, and how content strategies can be optimized. We would specifically be interested in identifying changes in engagement, monitoring digital trend data, and testing algorithms for analysis of sentiment. Through our analysis, we also hope to discover and display how different varieties of online content can influence simulated engagement and how data science can be used to understand different patterns in social media behavior.
